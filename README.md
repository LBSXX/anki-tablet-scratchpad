# Anki Tablet Scratchpad, Keyboard & Remote

A lightweight Anki desktop add-on that turns any tablet (iPad, Android, Surface) or smartphone into a **real-time handwritten scratchpad, remote keyboard, and review controller** via a simple web browser—no third-party app or cable required.

## Features
- **Live Handwritten Scratchpad:** Draw with Apple Pencil or any stylus; strokes mirror in real time on Anki Desktop (inline below the card with drag-to-resize borders, or in a detached floating window).
- **Drawing Tools:** Pen (4 colors), highlighter (3 colors), smart shape recognition (lines, arrows, circles), pixel eraser, stroke eraser, and white/grid/dotted backgrounds.
- **Save to Card:** Attach your handwritten notes directly to the current Anki note in one tap.
- **Live Remote Keyboard:** Type answers on your tablet/phone and sync them straight into Anki's `{{type:...}}` input field.
- **Full Review Remote:** Show answer, rate cards (*Again / Hard / Good / Easy*), undo, bury, or suspend cards from your device.

## Installation
1. Download the latest `.ankiaddon` file from the [**Releases**](../../releases) page.
2. Open Anki Desktop $\rightarrow$ **Tools** $\rightarrow$ **Add-ons** $\rightarrow$ **Install from file...** and select the downloaded `.ankiaddon` file.
3. Restart Anki.

## Usage
1. Start reviewing a deck on Anki Desktop (make sure **Brouillon : ON** is active in the top bar).
2. Open the local URL displayed on your card (e.g. `http://192.168.x.x:8765`) in Safari or Chrome on your tablet/phone connected to the same Wi-Fi or mobile hotspot.
3. *(iPadOS Tip)* Tap **Share $\rightarrow$ Add to Home Screen** in Safari for a full-screen distraction-free interface, and disable Apple Pencil *Scribble* in iPadOS Settings if needed.
